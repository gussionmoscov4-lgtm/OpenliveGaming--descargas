# OpenliveGaming--descargas
Aplicación para hacer directos de Youtube etc con RTMP y la clave de emisión aplicación muy sencilla y básica sin marcas de agua.
# ✨ Características principales

- 🎥 **Transmisión RTMP:** transmite en vivo utilizando una dirección RTMP y una clave de transmisión.
- ▶️ **YouTube Live:** transmite contenido directamente a YouTube mediante RTMP.
- 🔴 **Multi-stream:** transmite simultáneamente a múltiples destinos compatibles, según la configuración de la aplicación.
- 🎙️ **Micrófono:** captura tu voz durante las transmisiones.
- 🔊 **Audio del dispositivo:** permite transmitir el sonido interno del dispositivo cuando Android y la configuración de la aplicación lo permiten.
- 📱 **Captura de pantalla:** comparte la pantalla de tu dispositivo Android en directo.
- ⚙️ **Configuración de transmisión:** configura los destinos RTMP según tus necesidades.
🚫 No incluye anuncios ni marcas de agua
⚙️ Permite ajustar la resolución y fps
